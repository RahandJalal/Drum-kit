# 🥁 Interactive Drum Kit

An interactive web-based drum kit that plays realistic drum and percussion sounds triggered via mouse clicks or keyboard strokes.

---

## ✨ Features

- **Keyboard & Click Controls:** Play each instrument using specified keyboard keys (e.g., W, A, S, D, J, K, L) or by clicking the buttons.
- **Audio Feedback:** Instant sound playback using the HTML5 Audio API.
- **Button Animations:** Visual active-state animations when a drum is triggered.

---

## 🛠️ Built With

- **HTML5:** Semantic structure and drum pad layout.
- **CSS3:** Custom styling and interactive keypress animations.
- **JavaScript (ES6):** Event listeners (`keydown` and `click`), DOM manipulation, and dynamic Audio objects.
